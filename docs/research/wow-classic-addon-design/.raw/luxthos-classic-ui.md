# ~~[Classic AddOns & UI](https://www.luxthos.com/classic-addons-ui/)~~

Here is a simple list of all my AddOns that I use daily for World of Warcraft: Classic. I recommend using the [Twitch App](https://www.curseforge.com/twitch-client) to download, install and keep everything updated. Some of these AddOns might not be found on the Twitch App.

| Name | Description |
| --- | --- |
| Advanced Interface Options | Restores access to removed interface options. |
| Atlas | Instance Map Browser |
| AtlasLoot Classic | Shows the possible loot from bosses. |
| Auctionator | A lightweight addon that makes it easy and fast to buy, sell and manage auctions. |
| Battle for Azeroth UI | A Battle for Azeroth inspired User Interface. |
| ClassicAuraDurations | Restores cooldown swipe timers on default Target Frame and Blizzard Raid Frames. |
| Details! Damage Meter | Essential tool to impress that chick in your raid. |
| Fishing Buddy (Classic) | Help with fishing related tasks, clothing, fish information, etc. |
| KUI Nameplates | Pretty and useful nameplates. |
| Leatrix Maps | Enhancements for your maps. |
| Leatrix Plus | Quality of life addon. |
| Scrolling Loot Text | Show you all items you pick-up as a scrolling text, with the the number and value of the item and the color of the rarity as font color. |
| Titan Panel Classic | Adds a display bar on the top and/or bottom of the screen. Allows users to show and control information/launcher plugins. |
| WeakAuras 2 | A powerful, comprehensive untility for displaying graphics and information based on buffs, debuffs, and other triggers. |
| Zygor Guides Viewer Classic | Zygor Guides are high quality in-game strategy guides for World of Warcraft that will walk you step by step through every aspect of the game. |
| DejaClassicStats | Improved character stats panel view. |
| Questie | A standalone Classic Quest Helper. |
