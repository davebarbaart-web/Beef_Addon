# Auction House & Economy UIs

**Surface:** Auction browse/post, undercut, crafting queues  
**Flavors:** All Classic; TSM depth varies by economy size

---

## Dominant patterns

| Pattern | Exemplars | Notes |
|---------|-----------|-------|
| Lightweight AH helper | [Auctionator](https://www.curseforge.com/wow/addons/auctionator) | Undercut, shopping lists, simpler UX |
| Full economy suite | [TradeSkillMaster](https://www.curseforge.com/wow/addons/tradeskill-master) | Groups, operations, crafting queues |
| Legacy scanners | [Auctioneer](https://www.curseforge.com/wow/addons/auctioneer) | Price history / scan tooling (Anniversary lists still mention it) |
| Dense tabular UI | All of the above | Sortable columns, multi-step posting |

Anniversary profession sections bundle AtlasLoot + TSM/Auctioneer + gathering DB addons ([Overgear](https://overgear.com/guides/wow-classic/tbc-anniversary-top-addons/)).

---

## Version notes

| Flavor | Notes |
|--------|-------|
| **Era / SoD** | Auctionator-style light helpers popular; SoD markets spike with season phases |
| **Anniv** | Deep crafting/AH stacks for raid consumables |
| **Cata** | Same UX patterns; different commodities |

---

## Relevance to Church of Beef

- **Anti-pattern reference:** do not ship auction-density tables for a comedy rank ladder.
- Standing history = short event list, not a scroll of undercut rows.
- No AH integration in scope.
