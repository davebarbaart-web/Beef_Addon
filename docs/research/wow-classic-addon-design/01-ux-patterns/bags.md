# Bags & Inventory

**Surface:** Bags, bank, item search, gear sets  
**Flavors:** All Classic; bank UI width/search differ by client patches

---

## Dominant patterns

| Pattern | Exemplars | Notes |
|---------|-----------|-------|
| Combined bag window | [Bagnon](https://www.curseforge.com/wow/addons/bagnon), ElvUI bags | One searchable grid vs multiple bag frames |
| Bank as extension | Bagnon bank, ElvUI | Same search language across bag/bank |
| Gear set swap | [ItemRack Classic](https://www.curseforge.com/wow/addons/itemrack-classic) | Spec/role sets (tank/heal/farm) — big on TBC |
| Category / junk cues | Various bag addons | Greying junk, recipe highlights |

Listed under professions/interface essentials for Anniversary ([Overgear](https://overgear.com/guides/wow-classic/tbc-anniversary-top-addons/)).

---

## Version notes

| Flavor | Notes |
|--------|-------|
| **Era / SoD** | Smaller bag totals early; SoD still uses combined-bag QoL heavily |
| **Anniv (TBC)** | ItemRack-style set swapping common (multiple raid roles) |
| **Cata+** | Larger inventories; same combined-bag UX |

---

## Relevance to Church of Beef

- No bag UI. Avoid any pattern that feels like an item spreadsheet.
- If V2+ ever shows “relics” / scripture items, use a **simple list**, not a bag grid.
