# Loot

**Surface:** Loot distribution, rolls, council, drop lookup  
**Flavors:** All Classic; raid loot culture strongest in Anniv/Cata progression

---

## Dominant patterns

| Pattern | Exemplars | Notes |
|---------|-----------|-------|
| Raid loot master UI | [Gargul](https://www.curseforge.com/wow/addons/gargul) | Rolls, assignments, trade tracking — officer-led |
| Drop encyclopedia | [AtlasLoot Classic](https://www.curseforge.com/wow/addons/atlaslootclassic) | Browse dungeon/raid/vendor loot in-game |
| Softres / wishlist hybrids | Various (export/import) | Often external + in-game helper |
| Default loot frames | Blizzard | Still used when groups skip loot addons |

Gargul appears in Anniversary combat/raid tooling lists as the loot-distribution pick ([Overgear](https://overgear.com/guides/wow-classic/tbc-anniversary-top-addons/)).

---

## Version notes

| Flavor | Notes |
|--------|-------|
| **Era / SoD** | Smaller raid sizes / different loot speedruns; AtlasLoot still core |
| **Anniv** | SR/MS+OS/council workflows common in puGs → Gargul-type UIs |
| **Cata** | Valor/justice-era currencies change economy; loot addons still officer-centric |

---

## Relevance to Church of Beef

Closest **social UX cousin** to the Officer tab:

- Pending queue of people awaiting a decision  
- Officer-only actions (approve/reject ≈ award/pass)  
- Transparency about *why* (standing breakdown ≈ loot notes)  
- Everyone else can play without the addon; officers drive official state  

Do **not** copy Gargul’s dense raid-loot tables for the ladder — keep seven ranks scannable.
