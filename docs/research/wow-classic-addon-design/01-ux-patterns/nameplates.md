# Nameplates

**Surface:** Nameplates for enemies/friendlies, cast/debuff display on plates  
**Flavors:** All Classic; default plate styling shifted in 2026

---

## Dominant patterns

| Pattern | Exemplars | Notes |
|---------|-----------|-------|
| Scriptable plate engine | [Plater Nameplates](https://www.curseforge.com/wow/addons/plater-nameplates) | Cast colors, off-targets, mod profiles |
| Profile import culture | Plater + Wago shares | Raiders share dungeon/raid plate packs |
| Class-colored plates | Default CVars + Plater | Friendly/enemy class color options |
| Threat / interrupt focus | Plater mods, WA hybrids | Tank/DPS specific plate rules |

Anniversary combat stacks almost always include Plater ([Overgear](https://overgear.com/guides/wow-classic/tbc-anniversary-top-addons/)).

---

## Version notes

| Flavor | Notes |
|--------|-------|
| **All Classic (Jul 2026)** | Default nameplates modernized (Midnight-adjacent look). Class-color CVars documented for enemy/friendly plates: `nameplateShowClassColor`, `nameplateShowFriendlyClassColor` ([Blizzard Watch](https://blizzardwatch.com/2026/07/22/blizzard-modernized-parts-wow-classic-era-tbc-classic-anniversary-realms-user-interface/)). |
| **Era / SoD / Anniv / Cata** | Same plate API family with expansion-specific creature/spell data; Plater maintains Classic variants |

---

## Relevance to Church of Beef

- No nameplate integration in V1 (or likely ever) — wrong layer for guild ceremony.
- Awareness only: default UI is no longer “pure 2007 plates”; Beef’s later theatrical chrome should not assume players still see old Blizzard plates.
