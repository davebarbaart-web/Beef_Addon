# Quest Helpers & Progress Coordination

**Surface:** Quest objectives on map/minimap, dialogue UX, leveling routes, attunement tracking  
**Flavors:** Strongest on Era/Anniv leveling; attunements especially TBC Anniversary

---

## Dominant patterns

| Pattern | Exemplars | Notes |
|---------|-----------|-------|
| Map/minimap quest helper | [Questie](https://www.curseforge.com/wow/addons/questie) | Objectives, turn-ins, tooltips — Classic staple |
| Modernized gossip/quest text | [DialogueUI](https://www.curseforge.com/wow/addons/dialogueui) | Cleaner dialogue flow than default |
| Quest log browsers | EveryQuest-style addons | Searchable “what’s here” lists |
| Leveling route overlay | [RestedXP](https://www.curseforge.com/wow/addons/restedxp-guide) | Arrow/step guidance for speed leveling |
| **Guild progress / readiness** | [Attune](https://www.curseforge.com/wow/addons/attune) | Attunement trees + **guild survey** of who finished which step |

Anniversary questing stack commonly: Questie + DialogueUI + RestedXP; Attune called out for TBC gatekeeping ([Overgear](https://overgear.com/guides/wow-classic/tbc-anniversary-top-addons/)).

---

## Version notes

| Flavor | Notes |
|--------|-------|
| **Era** | Questie is near-mandatory for many players; no TBC attunement trees |
| **SoD** | Questie + season-specific guides; phase unlock tracking |
| **Anniv** | Attune’s survey/planner is the social standout; shared progress needs peers running the addon |
| **Cata** | Quest helpers still used; fewer “attunement saga” UIs than TBC |

---

## Relevance to Church of Beef

**Best social-coordination analogue in the Classic ecosystem:**

| Attune pattern | Beef analogue |
|----------------|---------------|
| Progress tree | Rank ladder |
| Survey guildmates | BeefNet sync / visible ladder occupants |
| Works better when more members install | Same soft dependency |
| No soft-lock if missing | Spec: players without addon must not soft-lock |
| Officer/raid lead planning tools | Officer tab approve/appoint |

Questie pin spam is what **not** to do for ranks. Attune’s clear progress + optional guild visibility is the pattern to steal.
