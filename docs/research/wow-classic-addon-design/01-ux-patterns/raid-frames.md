# Raid Frames

**Surface:** Party/raid grids, healer mouseover, dispel indicators  
**Flavors:** All Classic; Blizzard default frames modernized in 2026

---

## Dominant patterns

| Pattern | Exemplars | Notes |
|---------|-----------|-------|
| Compact heal grids | [Cell](https://www.curseforge.com/wow/addons/cell), [VuhDo](https://www.curseforge.com/wow/addons/vuhdo), Grid2, ElvUI raid | Health + debuff icons + range fade |
| Click-casting | [Clique](https://www.curseforge.com/wow/addons/clique) + any raid frames | Bind spells to mouse buttons on frames |
| Threat / aggro cues | ThreatClassic, built-in aggro | Edge glow or color shift |
| Blizzard raid options | Default CompactRaidFrames + Edit Mode | Color, dispel overlay toggles |

Anniversary guides call out Cell and VuhDo as healer staples alongside Clique ([Overgear](https://overgear.com/guides/wow-classic/tbc-anniversary-top-addons/)).

---

## Version notes

| Flavor | Notes |
|--------|-------|
| **All Classic (Jul 2026)** | Blizzard modernized raid-frame look toward Midnight-era styling; added health/background color options and dispellable-debuff indicators. Players can tune CVars (e.g. `raidFramesDispelIndicatorOverlay`) but cannot fully roll back the art ([Blizzard Watch](https://blizzardwatch.com/2026/07/22/blizzard-modernized-parts-wow-classic-era-tbc-classic-anniversary-realms-user-interface/), citing [Blizzard forum thread](https://us.forums.blizzard.com/en/wow/t/user-interface-updates-in-classic/2325408)). Affects Era, SoD, Hardcore, and Anniversary. |
| **Anniv / Cata** | 10/25 (and Cata flex-era) layouts drive more grid density than 5-man Era |

## Relevance to Church of Beef
