# Unit Frames

**Surface:** Player, target, focus, pet, party frames (non-raid grid)  
**Flavors:** All Classic; focus exists from TBC onward

---

## Dominant patterns

| Pattern | Exemplars | Notes |
|---------|-----------|-------|
| Full UF replacement | [ElvUI](https://tukui.org/elvui) unitframes | Unified backdrop, class-colored health, castbars |
| Modular movers | [MoveAnything](https://www.curseforge.com/wow/addons/move-anything) | Reposition default frames without full skin |
| Aura duration clarity | [ClassicAuraDurations](https://www.curseforge.com/wow/addons/classicauradurations) | Timers on buffs/debuffs — Classic default often opaque |
| Castbar emphasis | ElvUI, standalone castbar addons | Larger/interruptible cast feedback |
| Blizzard Edit Mode layouts | Built-in on modern Classic clients | Growing parity with retail layout tools |

Philosophy common in 2026 UI guides: self/target resources stay **near the character**; everything else pushes outward ([Medium UI 2026 guide](https://medium.com/@debonikawow/best-ui-for-wow-complete-guide-for-a-perfect-interface-in-2026-7c03bc12dce7) — retail-skewed but restates the gravity rule).

---

## Version notes

| Flavor | Notes |
|--------|-------|
| **Era** | No focus frame in original sense; party frames simpler |
| **Anniv (TBC)** | Focus + richer cast/channel UX expected; aura timer addons popular |
| **SoD** | Same Era-family frames + rune/seasonal tracking usually via overlays |
| **Cata** | More power types / totems / eclipse-era resources historically drove custom UF tags |

---

## Relevance to Church of Beef

- Ladder should **not** look like unit frames (no fake health bars for standing).
- Sparse class-color accents for names are fine; avoid healer-frame density.
- Local player highlight on the ladder ≈ “this is you” pattern from UF portrait highlight.
