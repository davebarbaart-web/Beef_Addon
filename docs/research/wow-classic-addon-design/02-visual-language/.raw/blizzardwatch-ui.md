# Blizzard has modernized some parts of the WoW Classic Era and TBC Classic anniversary realms user interface

By [Nick Marino](https://blizzardwatch.com/author/nmarino/)

[E-mail](mailto:?subject=Over%20the%20last%20week%2C%20Blizzard%20implemented%20user%20interface%20changes%20to%20World%20of%20Warcraft%20Classic%20realms%20and%C2%A0The%20Burning%20Crusade%20Classic%C2%A0anniversary%20realms%20that&body=https%3A%2F%2Fblizzardwatch.com%2F2026%2F07%2F22%2Fblizzard-modernized-parts-wow-classic-era-tbc-classic-anniversary-realms-user-interface%2F)

![](https://blizzardwatch.com/wp-content/uploads/2024/11/bw-wow-classic-anniversary-lfg-header.png)

Over the last week, Blizzard [implemented user interface changes](https://us.forums.blizzard.com/en/wow/t/user-interface-updates-in-classic/2325408) to [_World of Warcraft Classic_](https://blizzardwatch.com/category/warcraft/wow-classic/) realms and [_The Burning Crusade Classic_ anniversary](https://blizzardwatch.com/tag/tbc-classic-anniversary-realms/) realms that specifically affect the look of character name plates and raid frames, and also affect all _Classic_ realms including [Era](https://blizzardwatch.com/tag/classic-era/), [Season of Discovery](https://blizzardwatch.com/tag/season-of-discovery/), and [Hardcore](https://blizzardwatch.com/tag/wow-classic-hardcore/).

Blizzard has communicated these user interface changes, it feels more like a modernized update to the _Classic_ world and we’ve broken down what they are, how they affect the game now, and what changes could be in store for the future.

## What are the changes and why were they made?

- Raid Frames
  - Added options to select health bar color and background color
  - Added options to show or hide dispellable debuff indicators
- Edit Mode
  - Added Layout Template, Opacity, and Aura Icon Size Options
- Nameplates
  - Added option to color friendly or enemy nameplates based on player class color

There were also bugs affecting the size of the aura icons in the edit mode preview and the item comparison tooltip always showing that were fixed but the main thing really stands out is that the appearance of nameplate and raid frame are more in line with the styles used in _World of Warcraft Midnight._ This is intentional, as Blizzard explains that all _World of Warcraft Classic_ servers and realms, regardless of progression or state, share code with retail _World of Warcraft._ Whenever a _Classic_ release occurs, its code mirrors the corresponding current version of retail _WoW_( _Classic_ 2019 shared code with _[Battle for Azeroth](https://blizzardwatch.com/tag/battle-for-azeroth/),_ _TBC Classic_ anniversary with _[The War Within](https://blizzardwatch.com/tag/the-war-within/))._

After hearing unhappy player feedback, Blizzard provided some chat commands that **don’t roll back the UI to pre-update versions** but add some extra modifications, and plan to make these settings as part of the Options menu in the future:

- Nameplate Class Color (Enemy Units):
  - /script C\_CVar.SetCVar(“nameplateShowClassColor”, 1);
- Nameplate Class Color (Friendly Units):
  - /script C\_CVar.SetCVar(“nameplateShowFriendlyClassColor”, 1);
- Disabling Raid Frame Dispel Highlights:
  - /script C\_CVar.SetCVar(“raidFramesDispelIndicatorOverlay”, 0);

So, what’s the overall goal here?From a development standpoint, this shared code provides the easiest route for Blizzard to support and maintain each game in the long run despite the differing aspects of their time-locked state. The downside here is the permanence of the UI changes integrated that have no real visual rollback option. Sure, Edit Mode exists and has a _Classic_ pre-set, but even that itself is a tool from the retail version and its existence in _Classic_ is still a shift to the modern day.

Could Blizzard be moving to fully integrate retail _WoW_ UI into _Classic_? Maybe, but since the appeal of _Classic_ is the nostalgic, old-school look and feel, it’d be a bad overall move to do that and it makes more sense to preserve that aesthetic where possible.
