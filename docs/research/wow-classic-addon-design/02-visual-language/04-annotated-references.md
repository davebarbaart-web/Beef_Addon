## Primary addon homes

### ElvUI — Tukui
- **URL:** https://tukui.org/elvui  
- **Also:** https://github.com/tukui-org/ElvUI · https://github.com/tukui-org/ElvUI/wiki/custom-media  
- **Shows:** Official product page; ClassicTheme tank/healer screenshots; plugin aesthetics; version/changelog including Classic Anniversary / installer layout notes.  
- **Steal / adapt:** Unified token thinking (backdrop, border, font) for a *future* ornate skin flag; peaceful coexistence rules.  
- **Reject:** Flat grey “everything ElvUI” as Beef brand.  
- **Beef relevance:** Highest probability neighbor UI in the guild. Design `/beef` as a guest in ElvUI houses, not a rival skin.

### Bartender4 — CurseForge
- **URL:** https://www.curseforge.com/wow/addons/bartender4  
- **Shows:** Full bar replacement; alpha/fade; hide Blizzard artwork; Masque; Classic + modern clients.  
- **Steal / adapt:** Movable UI culture; optional hide of non-critical chrome later.  
- **Reject:** Borderless combat-bar aesthetic for social panels.  
- **Beef relevance:** Layout muscle memory only; no action bars in product scope.

### Dominos — CurseForge
- **URL:** https://www.curseforge.com/wow/addons/dominos  
- **Shows:** Movable bar parts; opacity; combat visibility; Masque per bar; config mode.  
- **Steal / adapt:** Config-mode drag affordance; per-element opacity philosophy.  
- **Reject:** Treating Dominos as “Domino” legacy of Bartender (incorrect).  
- **Beef relevance:** Same as Bartender — mobility/config UX reference.

### Plater Nameplates — CurseForge
- **URL:** https://www.curseforge.com/wow/addons/plater-nameplates  
- **Shows:** Scriptable plates, animations, profile sharing, combat density.  
- **Steal / adapt:** One-shot scripted rank-up spotlight (post-V1).  
- **Reject:** Persistent plate-like density in guild UI.  
- **Beef relevance:** Theater timing, not nameplate product.

### WeakAuras 2 — CurseForge / Wago / GitHub
- **URLs:** https://www.curseforge.com/wow/addons/weakauras-2 · https://wago.io/weakauras · https://github.com/WeakAuras/WeakAuras2  
- **Shows:** Display primitives; import culture; template UI screenshots.  
- **Steal / adapt:** Short center toast choreography; “important then gone.”  
- **Reject:** Screen-as-dashboard; constant pulses.  
- **Beef relevance:** Ceremony spectacle language for V2+; V1 prefers guild chat + single toast.

### Details! — CurseForge
- **URL:** https://www.curseforge.com/wow/addons/details  
- **Shows:** Dense meter windows, bookmarks, multi-display combat analysis.  
- **Steal / adapt:** Clear tabular navigation for officer tools.  
- **Reject:** Meter metaphor for standing; fake HP bars.  
- **Beef relevance:** Officer queue must stay human-readable comedy church, not parses.

### Questie — CurseForge
- **URL:** https://www.curseforge.com/wow/addons/questie  
- **Shows:** Classic quest helper; map pins; journey/config UI screenshots.  
- **Steal / adapt:** Icon/tooltip clarity; fantasy-readable pins.  
- **Reject:** Map spam for V1 ladder.  
- **Beef relevance:** Functional clarity over ornament; “Classic helper” tone.

### AtlasLoot Classic — CurseForge
- **URL:** https://www.curseforge.com/wow/addons/atlaslootclassic  
- **Note:** Deep-research also cited older “AtlasLoot Enhanced” pages; prefer Classic project for TBC Anniversary.  
- **Shows:** Tabbed loot browser; item-quality grammar; favourites; minimap entry.  
- **Steal / adapt:** Tabbed tool window; item-card scanning for ranks.  
- **Reject:** Full loot-table density on Ladder.  
- **Beef relevance:** Closest structural analogue to a seven-rank browser.

### Auctionator — CurseForge
- **URL:** https://www.curseforge.com/wow/addons/auctionator  
- **Shows:** Shopping/selling/cancelling tabs; Classic AH screenshots; list + actions.  
- **Steal / adapt:** Officer approve/reject as short list + primary actions.  
- **Reject:** Spreadsheet column overload on My Standing.  
- **Beef relevance:** Best “workbench” pattern for officer workflow.

## Guides and ecosystem context

### Overgear — TBC Anniversary top addons
- **URL:** https://overgear.com/guides/wow-classic/tbc-anniversary-top-addons/  
- **Shows:** How players cluster Interface (ElvUI, Bartender, Dominos) vs Combat (Plater, Details, WA) vs Questing/Professions (Questie, AtlasLoot, Auctionator).  
- **Steal / adapt:** Category mental model — Beef is **social/interface**, not combat.  
- **Beef relevance:** Positioning: do not market or look like a raid HUD.

### Luxthos — Classic AddOns & UI
- **URL:** https://www.luxthos.com/classic-addons-ui/  
- **Shows:** Streamer-adjacent Classic stack (Questie, AtlasLoot, Auctionator, Details, WA, etc.).  
- **Steal / adapt:** Streamer setups still keep tool windows + selective overlays.  
- **Beef relevance:** Stream readability; avoid packing every Luxthos combat toy into social UI.

### Blizzard Watch — Classic UI modernization (Jul 2026)
- **URL:** https://blizzardwatch.com/2026/07/22/blizzard-modernized-parts-wow-classic-era-tbc-classic-anniversary-realms-user-interface/  
- **Shows:** Shared retail code path; nameplate/raid frame/Edit Mode drift; player nostalgia friction.  
- **Steal / adapt:** Own a distinct guild window; don’t depend on Edit Mode.  
- **Beef relevance:** Aesthetic politics of Classic — Beef should feel intentional Classic institution, not accidental Midnight HUD.
