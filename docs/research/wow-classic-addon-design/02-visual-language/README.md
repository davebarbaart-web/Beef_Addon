## One-line stance for Church of Beef

**V1:** default Classic panel discipline (opaque, hard corners, Friz/default fonts, no glass).  
**Later art pass:** absurd religious institution chrome (Scarlet / cathedral / steak pageantry) *on top of* that discipline — not a retail HUD, not an ElvUI clone, not a raid meter.
