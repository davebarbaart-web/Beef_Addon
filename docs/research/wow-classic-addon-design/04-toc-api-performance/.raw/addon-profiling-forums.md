Tons of random apps throw in overlays and use hardware acceleration, which can mess stuff up with games and cause issues like this. Clip capturing features can do the same(they keep buffers of the last N seconds at all times and might be storing them in RAM).

Try closing out of every single other program bnet. In the bnet settings, disable hardware acceleration and reboot it(wait 30 seconds before relaunching the app since it lingers around in the processes for a bit after closing).

Within your task manager, verify that absolutely nothing else is using the GPU by right clicking on the column categories in the process list and adding “GPU engine.” Sort the processes by GPU engine (click a couple times till stuff shows up at the top). Make sure that absolutely nothing other than desktop window manager is there (some other windows processes will randomly blip on and off and that’s fine).

Disable any recording stuff like shadowplay. Go into start menu->settings->gaming->captures and disable “record what just happened.” Those types of features will tack their memory usage onto games and sometimes VRAM, if I’m not mistaken.

Open WoW and see if it changes anything.

And that sounds like a completely normal amount of ram usage for the game. Sometimes hardware acceleration can do funky things like that if they latch on to processes or if they compete for vram/shared memory.

Other than that, sounds like your situation is rectified. I wouldn’t be surprised though if WoW.exe is coded to make a pool size that is some fractional amount of your memory or something hardcoded like 8192mb, so don’t freak out if you see it up that high. It would likely drop down over time as the old assets in the pool get garbage collected.
