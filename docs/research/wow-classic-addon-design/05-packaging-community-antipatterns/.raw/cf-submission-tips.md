## Project Submission Guide and Tips

Modified on: Mon, 23 Dec, 2024 at 9:18 AM

Modding is fun, it customizes games and it makes for a new and better gaming experience overall.

As creators, you put in hard work into making your creations, and your project page is the best place to showcase that for millions of users to enjoy.

Your project page is the face of your creation - make it count!

If you're looking for inspiration - take a look at the popular projects in the category you're creating in, more often than not their project page is just as impressive as their mod or addon!

In this article you will find guidelines, tips and helpful suggestion to not only ensure your project [passes moderation](http://support.curseforge.com/en/support/solutions/articles/9000197279-project-and-modpack-moderation-policies), but that it succeeds in reaching more users.

## [Main Submission Page ▾](https://support.curseforge.com/support/solutions/articles/9000199552-project-submission-guide-and-tips\#Main)

- ### Game

Which game is the project for? Choose from the dropdown menu. If it's not in the list, [open a ticket and request a new game](https://support.curseforge.com/)!

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218117257/original/HMs8RIMukH649aMIXCB9a2hfcHuzh8HQVQ.png?1726056077)
- ### Project name

This should be a unique and distinct name, so make sure to check if a project with the same or highly similar name already exists.

Avoid version numbers, including the category name (mod/modpack/addon...) or excessively long names in general.![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218117223/original/9G7msMza8Ox4y29IsoqFI-PBMWm9qFo7hA.png?1726056076)
- ### Logo

This is your projects visual representation - So why not make it cool and stand out?!



This should be at least minimum 400\*400 px (1:1 scale) .png file. Anything larger will be downscaled to the appropriate size.



This cannot be a single colour blank square, and should be your original graphic, meaning that it should not use an existing project avatar, nor a generic game graphic such as the game's logo etc.



Your avatar can include the name of your project, but it doesn't have to!You should probably have this ready before you start the submission process. You can choose the file with a simple File Explorer that will open once you click 'Choose File'.![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218117226/original/I64S_fwTtOkT3qJ8L3DChOlnCmIgYGIy0w.png?1726056076)
- ### Summary

A summary is a one line explanation that offers the gist of what your creation offers.

Share what your project does, not who created it, or who is it for.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218117224/original/XBnwGOrrp0RMHiLYM5nLZhuYrcrnDxDmbg.png?1726056076)

- ### Class

Choose your project class . Not sure about it? Why not consult with peers in the [Discord server](https://discord.gg/curseforge) for advice!

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218117222/original/L534PAk34DWxY7MLsXHBCeVHjrv3iD8xDw.png?1726056076)
- ### Main category

This should be the outright distinctive category of your creation, so users can easily expect what they're going to get with a quick glance, or by filtering.

- ### Additional categories

If there are more relevant categories, mark them up so users can easily find them when filtering by category. You can choose up to 4 additional categories, but you can also leave this empty.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218117229/original/7fSzuUFCV2E_PrqTPgPBZqaMiK13MKMeZw.png?1726056076)
- ### Allow Comments

\\* Allow Comments Toggle - We encourage creators to enable a communication channel with users for feedback, requests and bug reporting. If you prefer to toggle off comments, we suggest adding links and referring your audience to an alternative option within the description.

- ### Experimental

This means the project will not sync with the CurseForge ecosystem. This option is recommended mostly for experienced authors who understand the benefits and limitations of this project type.



You can read more about this, as well as how you can submit an experimental project to 'non-experimental' status from your project page [Here](https://support.curseforge.com/en/support/solutions/articles/9000197242).

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218117227/original/O1M4iEP_r7n3hUHnVdUk_G5J7YlKWdCChQ.png?1726056076)Y
- ### WWYSIWYG/Markdown

These are the two text-editor options that you can choose from. If you are not sure which to use, we recommend the default WYSIWYG (which stand for 'What You See Is What You Get")![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218117221/original/4zIiv7i3JdDeoTAaWQqJTRPB1Sh4yIyusQ.png?1726056076)
- ### Description

The Description is an opportunity to tell the story behind you creation. What makes it unique, what experience does it provide. You can embed images and videos or mention notable mods.

This is also the place to share your socials and invite users to join your community if you'd like, add credit to whom it's due and add functional instructions for installing or running your creation.

The Description is the most open section in the project submission process, however you should consider the dos and don'ts mentioned in the [Moderation Policies](http://support.curseforge.com/en/support/solutions/articles/9000197279-project-and-modpack-moderation-policies).



**Note:** Partnership affiliations and donation links - You may add Server Hosting partnerships links or banners if you have any but keep them civil in size and at the bottom of the page. Keep the users in mind!

The same is true with donation sites. Additionally, avoid advertising paywalled features available for donators. What you do in the donation site is your concern and liability.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218117231/original/-jdAUDGzWsLOp-ZYTXult-JasCgsbRjHyA.png?1726056076)
- ### License

Choose from a list of available licenses or write your own with 'Custom'.

Attention! If you are forking/porting a project or remaking it - please make sure the license of the original project allows it, and if it requires your license to follow suit (such as GNU License).



Note that if ported/forked projects are available in additional repositories and there is a conflict between licenses, our moderation refers to the license as it appears in the CurseForge project page.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218117219/original/bFDFvuwNbmTwRb_ozHscAxhEIizazMozIg.png?1726056076)

After you choose a license, You can review it by clicking on "View full license".



**And that's it!**

Your Project will now head over to moderation, where several automated and manual processes are run to make sure your project follows our standards.

If your project requires changes, you will receive more specific instructions which you can access in your notification area, or head over to [https://www.curseforge.com/my-notifications](https://www.curseforge.com/my-notifications).



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218117225/original/Dw3RKBU8LziL-s9VIkrOhSOF6-vSo1Ugdg.png?1726056076)

## [More Options (once your project is created) ▾](https://support.curseforge.com/support/solutions/articles/9000199552-project-submission-guide-and-tips\#moreoptions)

- ### Rewards Program

Your projects can earn you rewards! If you want to join the reward program, make sure to set it up. Read more about that [here](https://support.curseforge.com/en/support/solutions/articles/9000197709).
- ### Images

In-game screenshots with the mod enabled are a great way to quickly display what your creation is all about. You can also upload images to highlight UI instructions to enable the mod or addon. You can add image files by going to the image tab
- ### Files

You can add the mod files by going to the file tab and following the instructions there. ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218118288/original/8js8EB4GPDDTBvv8mDjKMTWH1akQ5UiGAw.png?1726056939)

## [Managing Your Project ▾](https://support.curseforge.com/support/solutions/articles/9000199552-project-submission-guide-and-tips\#manageproject)

Clicking the"project tab" in your dashboard and then selecting a specific project will allow you to edit it after creation. In addition to all the previously mentioned fields, you also have access to several new ones.

Note - only project owners or members with access can edit these segments.

- ### [Donation Method ▾](https://support.curseforge.com/support/solutions/articles/9000199552-project-submission-guide-and-tips\#donation)


You can add your preferred donation method from our list here, making donations one click easier, in a visible area.

- ### [Wiki ▾](https://support.curseforge.com/support/solutions/articles/9000199552-project-submission-guide-and-tips\#wiki)


If your project has a wiki entry, this is where you can link it.

- ### [Issues Tracker ▾](https://support.curseforge.com/support/solutions/articles/9000199552-project-submission-guide-and-tips\#tracker)


You can use the internal tracker (on CurseForge), or an external one if your project is on GitHub, or any other tracker website service.

- ### [Source ▾](https://support.curseforge.com/support/solutions/articles/9000199552-project-submission-guide-and-tips\#Source)


If your code is up and available in other sites and you want people to have access to it, this option is for you!

- ### [Members ▾](https://support.curseforge.com/support/solutions/articles/9000199552-project-submission-guide-and-tips\#Members)


Add other CurseForge users that are part of the project and assign them a role and permissions so they get recognition, access, and reward points split.

- ### [Delete Project ▾](https://support.curseforge.com/support/solutions/articles/9000199552-project-submission-guide-and-tips\#DeleteProject)




While it's sad to see a project go, this is the place to do so should you wish. There are other options if you simply don't want a project to sync to the system anymore, read about those [here](https://support.curseforge.com/en/support/solutions/articles/9000197242).
