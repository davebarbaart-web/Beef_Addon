## [How can I remove a game installation/instance from the app? ▾](https://support.curseforge.com/support/solutions/articles/9000198422-world-of-warcraft-addons-faq-and-troubleshooting\#instance)

Game instances cannot be completely removed but they can be disabled, through the app's settings.

Please follow these steps:

1. Open the app's settings
2. Select 'World of Warcraft' from the menu
3. Under 'Game Instance', select the instance that you wish to disable from the dropdown list
4. Toggle off the option 'Manage addons for this instance'



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9234771402/original/vj2VNkO4SMWtid6OmEvPb1juaC0njfCNkw.png?1753696823)

## [How do I install an addon specifically for Retail/Classic/Classic Era? ▾](https://support.curseforge.com/support/solutions/articles/9000198422-world-of-warcraft-addons-faq-and-troubleshooting\#flavors)

If you have more than one World of Warcraft flavor installed, you will notice a dropdown menu next to the 'Run Game' button:

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9208028422/original/RC0UsisRtKHO8Xxd7-HvlQMniwtmxGR05g.png?1710938189)

Let's say you want to install a certain addon for WoW Classic -

First, select 'Classic' from the dropdown menu, then click 'Featured' or 'Browse':

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9208028469/original/ye4YYMtxltpYNT8GbCRzAgktCeqrUeOW8g.png?1710938227)

You can also type in the name of an addon in the search bar and press 'Enter' to initiate the search:

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9208028601/original/g6GjJ7XKFaS5-BfbAk9whXKykVVf6e4gZw.png?1710938301)

Click the 'Install' button next to your preferred addon and that's it!

Once the installation is finished you can click the WoW icon in the sidebar and view your installed addons.

## [I reinstalled/about to reinstall World of Warcraft. How can I make sure all my addons and their settings are saved? ▾](https://support.curseforge.com/support/solutions/articles/9000198422-world-of-warcraft-addons-faq-and-troubleshooting\#reinstall)

There are two ways to save your addons in order to restore them after reinstalling the game:

1. Creating a Sync Profile - A Sync Profile will allow you to sync your addon between different computers in case you are reinstalling the game on a different device.
2. Creating a backup of the game's 'Addons' and 'WTF' folders.

## [I'm looking for a specific addon, but can't find it in the website/app ▾](https://support.curseforge.com/support/solutions/articles/9000198422-world-of-warcraft-addons-faq-and-troubleshooting\#cantfindaddon)

If you're unable to find an addon in the CurseForge website or app, it can mean:

1. **That the mod is pending review by CurseForge's moderators**, and should be available once it's approved.

Project/File moderation is done between 8AM to 3PM CET (11PM-6AM PST), 7 days a week, excluding holidays.

This process is First in, First out and any files submitted late in the day may not be checked until the next review day.



Or

2. **The addon had not been uploaded to the CurseForge repository**

Mods and addons in the CurseForge repository are submitted and managed directly by their creators.

Some authors prefer to host their addons and mods in other sources, in which case their projects will not be available in CurseForge.



If you would like to see an addons or mods you enjoy in CurseForge, contact the authors and submit a request to them.

## [Addon Warnings ▾](https://support.curseforge.com/support/solutions/articles/9000198422-world-of-warcraft-addons-faq-and-troubleshooting\#warnings)

The app's warning provide are meant to provide an indication in case the app observe certain incompatibilities or inconsistencies in addon files, so that you can be informed before launching the game.

**A warning does not necessarily mean that the addon it is shown for will not work in-game.**

It might still work perfectly fine despite the warning, but other times it might not, until the inconsistency is resolved.

- ### This addon might be corrupt (Reinstall/Update)        ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218116525/original/Sw3jhocpqqhsTi0Ja41mCKQBEVYqFgKSKg.png?1726055477)


This warning indicates that there might be an inconsistency between the installed addon file and the information on the file in CurseForge's servers.



If there's an update available for the addon, please install it, and if there isn't - try to reinstall it:



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218116517/original/9OQ-y0iez5SxkpPizoWJSkhMtNYu0hCJSw.png?1726055456)

- ### This addon might be corrupt (Belongs to...)        ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218116706/original/NZttcwvbnxRjXVuXVBOiQLdkdpxc4UNvSg.png?1726055673)


This warning indicates that the game flavor the addon's file is compatible with does not match the game flavor it is installed to.



To resolve the issue, uninstall the addon, search for it while set on the relevant game flavor (to only get results that are compatible with this flavor) and install it from the list of results.



If you cannot find the addon when searching for it through a certain flavor, it's possible that there isn't a version of it that is compatible with that flavor.

- ### This addon's files were modified



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9218120703/original/5ttLCh4QPEU6OWIWOn97MHok5ynR_k0c2g.png?1726058757)

The app will display this warning when it detects that the addon's files were modified locally, or if there is some type of issue on the app's side.

If updating/reinstalling the addon does not resolve the issue, please [reach out to us](https://support.curseforge.com/en/support/tickets/new) with your [CurseForge logs](https://support.curseforge.com/en/support/solutions/articles/9000218900-how-to-get-your-curseforge-logs) and the addon's folder, and we will investigate it.


\*\*Please note that mods in 'Modified' or 'Working Copy' states will not get automatically updated. This is not an issue, but rather made intentionally in order to protect these mods' files from getting overwritten or deleted by updates.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9219673389/original/V3bOy9_qJKY92EcTnoEbOnesmbRKq8P29g.png?1728481244)

## [How do I use the Sync feature? ▾](https://support.curseforge.com/support/solutions/articles/9000198422-world-of-warcraft-addons-faq-and-troubleshooting\#sync)

The Sync feature allows you to sync your addon installations between 2 (or more) devices.

### [Creating a sync profile ▾](https://support.curseforge.com/support/solutions/articles/9000198422-world-of-warcraft-addons-faq-and-troubleshooting\#create-sync-profile)

1. Log in with your Twitch user by clicking the button in the side menu:



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9208028965/original/EwlHPk0Y5fXFy-FN1F2b2RalQXXi4FAPpg.png?1710938495)

2. Click 'Sync'



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9208029059/original/5NovsIJsoSGjPz4W2aq45HALoSTEOdnmDA.png?1710938556)

3. Check the box for 'Enable AddonSync', type a name for your new profile and click 'Create'



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9208029107/original/2dulEmwu5FpIivmBch3psaAcf_MF5RDAvw.png?1710938579)

4. Your currently installed addons will be automatically synced to the profile. You can view the last sync time, initiate a sync and select additional settings



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9137829019/original/zeYQ8nExzEu14XdTYQqa9LwrQiNTniPJFQ.png?1629878860)

Please note that the 'Backup' option is not available yet.

5. If you wish your additional flavors' addons to be synced to the same profile, select the flavor, click 'Sync', choose the profile that you created and click 'Join'



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9137829356/original/ekQnsVXOQp3e4vDeu8WvxzjLYZFWM1Lelw.png?1629879115)

Then 'Upload'



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9137829410/original/xZLSr9b2yQPa1gL3oWX3juP3Gfpjbn1kjw.png?1629879180)

All your synced flavors will be listed in the sync profile



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9137829573/original/KGiOibRmyiTcOa2WxDHiXRP0ueBfWFC1Cw.png?1629879281)


### [Adding a device to an existing profile ▾](https://support.curseforge.com/support/solutions/articles/9000198422-world-of-warcraft-addons-faq-and-troubleshooting\#add-device)

To connect to your sync profile from a different device, please follow these steps:

1. Enable the addon sync



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9137853544/original/gTsU-Noboqxm8HXtt2vIDsMNRFF0m6Yefw.png?1629897823)

2. Select your existing profile, click 'Join' and then click either 'Download' or 'Upload'



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9137853285/original/drp_0z4uBJiCt0jcmPHvoms9BdOoKJrwGA.jpeg?1629897693)

3. Your profile will now include the new device



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/9137861584/original/z5Np234Nkj9WjQqgRczdz-6ERM5cr0ckQQ.png?1629901394)
