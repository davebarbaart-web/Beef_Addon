## Avoid (research red flags)

| Anti-pattern | Why it fails here |
|--------------|-------------------|
| Pure numeric global standing as default view | Stale elites; DKP-sheet vibe; demotivates rookies |
| Continuous point decay | Classic honor decay was hated and removed; anti-casual |
| Auto-promote on threshold | Invites SV edits; kills officer theater |
| EPGP/DKP table UX (PR sorts, bid panels) | Wrong job (loot); imports toxicity debates |
| Win-only duel scoring | Players dodge Gora |
| Open-world / city co-play points | Unpoliceable farm |
| Always-on combat HUD ladder | Competes with DBM/WA; wrong surface |
| External website as system of record | Split brain; ToS anxiety; offline drama |
| Shame boards / “lowest beef” sorts | Toxic comparison by design |
| Hidden officer bonus multipliers | Favoritism narrative from DKP culture |
| Points-for-everything streaks / daily login guilt | Extrinsic noise; wrong comedy tone |
| Cross-realm shared church state | Spec forbids; sync nightmare |
| Cryptographic “prove points” schemes | Out of scope; officer gate is enough |
| Treating rank as skill MMR | Identity toxicity; hours≠faith |

## Grey area (postpone, don’t invent in V1)

| Idea | Verdict |
|------|---------|
| Weekly “movers” micro-board | Good later; not required for V1 hero |
| Opt-in prestige / Lenten vow | Good seasonal content after saturation |
| Account-linked alts | Open question §16 — do not silently merge |
| Mild suggestion soft-cap on inactivity | Only if demote/season tools feel too blunt |
| Friends-only rivalry strip | Nice-to-have; guild *is* already the cohort |

## One-line product test

If removing the comedy titles would leave a DKP addon, redesign. If removing the officer gate would leave a self-serve Elo grind, redesign. Beef is **title theater with capped participation scores and human clergy**.
