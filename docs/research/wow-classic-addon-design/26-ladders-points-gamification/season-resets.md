# Season resets, soft resets, and decay

**Track:** 26 · **Scope:** When and how to reset ladders so aspiration returns without turning comedy standing into a second job.

## Spec anchor

- **V1:** no automatic decay; points only go up; officers can demote manually ([§4.3](../../../superpowers/specs/2026-07-25-church-of-beef-design.md)).
- **Open question (§16):** if everyone saturates at Beef Butcher, revisit seasonal resets or decay — a **“Lent” season reset** is called out as on-brand.

## Lessons from WoW ladders

### Honor / rank systems (Classic family)

Classic’s honor economy historically combined **weekly standing**, rank thresholds, and (in original design) **decay** so inactivity hurt rank maintenance. Player guides still document diminishing returns on repeated kills of the same targets within a day — an anti-farm curve that rewards variety over camping the same body ([Boosting-Ground honor overview](https://boosting-ground.com/wow-classic/guides/pvp-guides/wow-classic-honor-system); [Wowpedia Honor system (Classic)](https://wowpedia.fandom.com/wiki/Honor_system_(Classic))).

Blizzard later **removed honor decay entirely** from Classic Era / SoD (announced late 2023) after the community treated maintenance grind as punitive rather than motivating ([Wowhead: Decay removed](https://www.wowhead.com/classic/news/decay-being-removed-entirely-from-pvp-honor-system-wow-classic-336421)). Separate Era patch notes also used **explicit rank resets** when relaunching PvP systems (e.g. Hardcore-era 1.14.4 discussions) ([Blizzard forum: Classic Era PvP Rank Reset](https://us.forums.blizzard.com/en/wow/t/classic-era-pvp-rank-reset-coming-with-patch-1144/1596356)).

**Takeaway for Beef:** Continuous decay trains “must log or lose status.” That is anti-comedy and anti-casual. Prefer **scheduled soft resets** (ceremony) over silent drip decay.

### Arena / PvP seasons

PvP seasons reset **personal ratings** (and sometimes MMR), refresh reward tracks, and reopen the climb ([Wowpedia: PvP season](https://wowpedia.fandom.com/wiki/PvP_season)). The psychological deal: progress evaporates so the ladder can matter again — also the burnout risk when rank becomes identity ([Gaming leaderboards and toxic behavior](https://leaderboarded.com/blog/posts/leaderboards-in-gaming/)).

**Takeaway for Beef:** If you reset, make it a **named guild event** with spectacle (Lent, Jubilee, Prophet decree), not a silent SV wipe. Preserve titles people care about as *history* even if standing numbers soft-reset.

### Prestige (other genres)

Prestige systems reset level/progress in exchange for cosmetics or status tokens (e.g. CoD-style prestige loops) ([Turtle Beach: BO6 Prestige](https://www.turtlebeach.com/blog/black-ops-6-how-does-the-prestige-system-work-explained)). Useful metaphor: **opt-in reset for glory**, not mandatory wipe.

**Takeaway for Beef:** Optional “take the Lenten vow” (opt-in standing soft-reset for a seasonal cosmetic title) is healthier than forced wipe of everyone’s comedy history.

## EPGP-style decay (loot economies — caution)

EPGP decays EP/GP percentages so hoarding dies and recent attendance matters; Min EP / Base GP tune eligibility ([Wowpedia: EPGP](https://wowpedia.fandom.com/wiki/EPGP)). That solves **loot fairness**, not fun-score theater.

**Beef should not import EPGP decay math** for V1 or early V2. If saturation happens, prefer:

1. Officer demote / excommunication events (already first-class).
2. Seat scarcity at Council / Prophet (already first-class).
3. Optional seasonal standing soft-reset announced in guild chat.
4. Only later: mild inactivity soft-cap on *suggestions*, not silent point theft.

## Recommended reset ladder for Beef

| Phase | Mechanism | When |
|-------|-----------|------|
| V1 | No decay; officer demote; scarce top seats | Ship default |
| Saturation watch | Track % at Beef Butcher / suggestion backlog | Playtest metric |
| Soft season (“Lent”) | Officer starts season: standing → floor or ×factor; titles may stay or get seasonal suffix | Guild decree |
| Prestige opt-in | Member vows reset for seasonal flair | Optional |
| Hard wipe | Full ladder erase | Avoid unless new guild / realm relaunch |

## Design rules if a season ships later

1. **Announce in guild chat** (same spectacle pipe as promotions).
2. **Revision bump** all affected records so BeefNet converges.
3. **Keep event logs / lore** (“former Prophet”) even if standing resets.
4. **Never auto-reset** without Officer+ action — matches authority model.
5. **Do not** couple season reset to real-money or mandatory attendance quotas.
