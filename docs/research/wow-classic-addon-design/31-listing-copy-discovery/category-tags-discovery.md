# Category tags & discovery SEO

**Maps to:** Where Church of Beef appears in CurseForge / Wago browse filters.

## CurseForge listing metadata (discovery surface)

| Field | Role in discovery | Hard rules |
|-------|-------------------|------------|
| **Name** | Unique title in search | Unique; no version numbers / “addon” padding ([Project Submission Guide](https://support.curseforge.com/en/support/solutions/articles/9000199552-project-submission-guide-and-tips)) |
| **Summary** | One-line card blurb in search/browse | Short purpose + synopsis ([Creating and Submitting a Project](https://support.curseforge.com/en/support/solutions/articles/9000197241-creating-and-submitting-a-project); [Best Project Page](https://blog.curseforge.com/how-to-create-the-best-project-page/)) |
| **Class** | Root = Addons for WoW | Wrong class breaks app support ([Creating and Submitting a Project](https://support.curseforge.com/en/support/solutions/articles/9000197241-creating-and-submitting-a-project)) |
| **Main category** | Primary browse bucket | One main |
| **Additional categories** | Extra filter hits | Up to **4**; irrelevant tags → moderation bounce ([Creating and Submitting a Project](https://support.curseforge.com/en/support/solutions/articles/9000197241-creating-and-submitting-a-project)) |
| **Logo** | Tile identity | ≥ **400×400** PNG 1:1 ([Project Submission Guide](https://support.curseforge.com/en/support/solutions/articles/9000199552-project-submission-guide-and-tips)) |
| **Game version / flavor files** | Classic Era vs Classic TBC vs MoP Classic filters | Players filter flavor before reading prose (observed across [Questie](https://www.curseforge.com/wow/addons/questie), [Attune](https://www.curseforge.com/wow/addons/attune), [Gargul](https://www.curseforge.com/wow/addons/gargul)) |

Titles and descriptions must be **English** for moderation ([Creating and Submitting a Project](https://support.curseforge.com/en/support/solutions/articles/9000197241-creating-and-submitting-a-project)).

## WoW category taxonomy (relevant to Beef)

Browse exposes buckets such as Roleplay, Guild, Chat & Communication, Data Export, Tooltip, Map & Minimap, Quests & Leveling, Combat, Boss Encounters, Miscellaneous, etc. ([Roleplay category browse](https://www.curseforge.com/wow/search?categories=roleplay&class=addons&page=1&pageSize=20&sortBy=relevancy); [Guild category browse](https://www.curseforge.com/wow/search?class=addons&page=1&pageSize=20&sortBy=relevancy&categories=guild)).

### How successful cousins tag (observed)

| Addon | Summary pattern | Categories (CF) | Notes |
|-------|-----------------|-----------------|-------|
| [Questie](https://www.curseforge.com/wow/addons/questie) | “The Classic Quest Helper” | Quests & Leveling, Map & Minimap, Tooltip | Job words in summary; map/tooltip secondary |
| [Total RP 3](https://www.curseforge.com/wow/addons/total-rp-3) | “The best role-playing add-on…” | Roleplay (main) | Owns one clear niche |
| [Attune](https://www.curseforge.com/wow/addons/attune) | “Attunement progress” | Data Export, Quests & Leveling | Guild survey is product; “Guild” not used on CF (under-tagged vs behavior) |
| [Gargul](https://www.curseforge.com/wow/addons/gargul) (CF) | Feature dump: GDKP, TMB, SoftRes, Auto Loot | Bags & Inventory, Buffs & Debuffs, Data Export, Tooltip | Officer loot tool tagged by surfaces, not “Guild” |
| [Gargul](https://addons.wago.io/addons/gargul) (Wago) | Same story | Chat & Communication, **Guild**, Bags & Inventory, Tooltip | Wago explicitly uses **Guild** |
| [DBM](https://www.curseforge.com/wow/addons/deadly-boss-mods) | Player-centric combat promise | Boss Encounters, Combat, PvP | Combat stack — anti-pattern for Beef positioning |

**Insight:** “Guild” is a real CF category and appears in Guild browse next to world buffs, loot council, profession guild tools ([Guild browse](https://www.curseforge.com/wow/search?class=addons&page=1&pageSize=20&sortBy=relevancy&categories=guild)), but some guild-adjacent hits (Attune) skip it. Beef should **not** skip Guild — it is the honest primary job.

## Recommended Beef category plan (draft)

| Slot | Category | Why |
|------|----------|-----|
| **Main** | **Guild** | Ladder, officer approve, guild-chat spectacle |
| Additional | **Roleplay** | Church / titles / ceremony framing (honest if copy leads with institution, not DPS) |
| Additional | **Chat & Communication** | Throttled guild-chat announcements are a V1 success criterion |
| Additional | **Data Export** *or* skip | Only if officer sync/export is marketed; Attune precedent — optional |
| Additional | **Miscellaneous** | Avoid unless nothing else fits; weak SEO |
| **Do not use** | Combat, Boss Encounters, HUDs, Quests & Leveling | False discovery + wrong player expectations |

Cap at main + ≤4. Prefer **Guild + Roleplay + Chat & Communication** (three strong, honest tags) over stuffing four weak ones ([Creating and Submitting a Project](https://support.curseforge.com/en/support/solutions/articles/9000197241-creating-and-submitting-a-project)).

## Wago Addons discovery

- [Wago Addons](https://addons.wago.io/) is a parallel host; managers treat CF and Wago as separate catalogs ([Blizzard forums](https://us.forums.blizzard.com/en/wow/t/wow-up-curse-wago/2292441)).
- Project pages use About / Releases / Gallery tabs; categories are multi-select (Gargul: Chat, Guild, Bags, Tooltip) ([Gargul on Wago](https://addons.wago.io/addons/gargul)).
- Mirror CF tags where taxonomy overlaps; keep **Guild** on Wago even if CF cousins underuse it.

## SEO / search keywords (Classic players)

Players search and filter for:

1. **Flavor** — “Classic TBC”, Anniversary, Era (file tags + copy first paragraph).
2. **Job nouns** — guild, ladder, ranks, officer, loot council (cousin), attunement (cousin), roleplay, stream.
3. **Not** — DPS, meter, WeakAuras, DBM (wrong funnel).

Put job nouns in **Summary** and H1-equivalent description openers. Questie’s three-word summary and Attune’s two-word summary show brevity wins on cards ([Questie](https://www.curseforge.com/wow/addons/questie); [Attune](https://www.curseforge.com/wow/addons/attune)).

## Anti-patterns

- Tagging Combat/Boss Encounters “for visibility” → moderation risk + angry combat players ([Creating and Submitting a Project](https://support.curseforge.com/en/support/solutions/articles/9000197241-creating-and-submitting-a-project)).
- Name stuffing: `Church of Beef Guild Ladder Addon Classic TBC` — CF asks to avoid category words and long names ([Project Submission Guide](https://support.curseforge.com/en/support/solutions/articles/9000199552-project-submission-guide-and-tips)). Prefer clean **Church of Beef**; put Classic/Anniversary in Summary/Description.
- Relying on CF alone if the guild uses Wago/WowUp — dual publish ([Blizzard forums](https://us.forums.blizzard.com/en/wow/t/wow-up-curse-wago/2292441)).
