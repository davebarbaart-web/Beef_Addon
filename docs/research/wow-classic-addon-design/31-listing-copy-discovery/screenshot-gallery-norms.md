# Screenshot & gallery norms

**Maps to:** CurseForge Images / Gallery tab and Wago Gallery — first visual proof after the Summary.

## Official CurseForge guidance

- Use the project **Images** tab for previews (title + description per image); embed media in the long description as well when useful ([Creating and Submitting a Project](https://support.curseforge.com/en/support/solutions/articles/9000197241-creating-and-submitting-a-project); [Best Project Page](https://blog.curseforge.com/how-to-create-the-best-project-page/)).
- Prefer **in-game screenshots with the addon enabled**; UI-instruction shots are explicitly encouraged ([Project Submission Guide](https://support.curseforge.com/en/support/solutions/articles/9000199552-project-submission-guide-and-tips)).
- Showcase “as many examples of in-game features” as practical ([Best Project Page](https://blog.curseforge.com/how-to-create-the-best-project-page/)).
- **Logo:** ≥400×400 PNG, 1:1, distinct ([Project Submission Guide](https://support.curseforge.com/en/support/solutions/articles/9000199552-project-submission-guide-and-tips)).
- AI-modified showcase images that may misrepresent content need a clear disclaimer ([Moderation Policies](https://support.curseforge.com/en/support/solutions/articles/9000197279-moderation-policies)).
- Social badges: top badge strip or bottom of description — reasonable size, don’t overwhelm ([Best Project Page](https://blog.curseforge.com/how-to-create-the-best-project-page/); [Moderation Policies](https://support.curseforge.com/en/support/solutions/articles/9000197279-moderation-policies)).

WoW addons are not in the “texture packs require ≥1 gallery image” Minecraft/Sims carve-outs, but living pages that convert still treat gallery as mandatory marketing ([Attune](https://www.curseforge.com/wow/addons/attune) Gallery 10; [Gargul](https://www.curseforge.com/wow/addons/gargul) Gallery 8; [Total RP 3](https://www.curseforge.com/wow/addons/total-rp-3) Gallery 8; [DBM](https://www.curseforge.com/wow/addons/deadly-boss-mods) Gallery 6).

## Classic-specific screenshot hygiene

1. **Hide combat clutter** for Beef shots — no DBM bars / WA spam covering the product (Beef is edge social; center-mass clutter reads as “another HUD”).
2. **Show guild chat spectacle** if V1 announces promotions — one frame of guild chat with a rank line is more persuasive than empty chrome (spec success criterion §13.11).
3. **Officer vs member** — two frames: member ladder view vs officer approval queue (Attune’s survey/raid-planner split is the cousin pattern).
4. **Stream-safe framing** — if marketing stream use, leave title-safe margins (see track 17); don’t put critical text under typical OBS overlays.
5. **No fake AI mockups** of unbuilt ceremonial V2 chrome — CF AI-disclaimer policy + trust hit ([Moderation Policies](https://support.curseforge.com/en/support/solutions/articles/9000197279-moderation-policies)).

## Logo norms

- Square, high-contrast at 64px and 400px (app tiles shrink hard).
- Brand: Church of Beef / gothic-absurd institution — not a generic sword icon competing with DBM/Questie.
- Avoid embedding long taglines in the logo PNG; taglines belong in Summary.
