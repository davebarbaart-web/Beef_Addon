# Transparency norms

**Maps to:** Spec §10 guild-chat announce, §6.3 human judgment, §7.3 officer-visible breakdown  
**Question:** Which social norms keep a judgment-based ladder from rotting into favoritism theater?

---

## Culture findings (loot cousins → Beef)

Cross-cutting claim from [Guild Order](https://guildorder.com/games/wow/guides/loot-systems-dkp-vs-epgp):

- There is no neutral judgment system.  
- Loot Council dies when criteria are unpublished (“we discussed it”).  
- Survival pattern: **honest system + consistent administration + written rubric**.  
- “Loot is the second-most-common reason raiders leave; the first is officer drama” — rank disputes will wear the same costume.

[Guild Order wiki — making LC work](https://guildorder.com/games/wow/wiki/loot-systems): publish priorities, explain decisions when asked, maintain a **public log** of distributions.

[CEPGP / EPGP note culture](https://www.wowinterface.com/downloads/info25051-CEPGP.html): many guilds keep officer notes **viewable by all** so standings are not a secret cabal spreadsheet — transparency via shared read access, privilege via edit access ([EPGP public-notes discussion](https://github.com/Ex1sten/epgp/issues/493)).

Beef already splits **read** (ladder/My Standing for all addon users) from **write** (Officer+ commits). Norms should reinforce that split.

---

## Norms worth adopting for Church of Beef

### 1. Publish the rubric

In-guild pin + short in-addon help:

- What grants standing (instance drip, ceremony, Gora — losses pay).  
- Caps / anti-AFK (no door-AFK).  
- Ranks 1–5 are suggestion-eligible; Council/Prophet are appointed/bestowed.  
- Officers may reject even when eligible; standing usually remains.  
- Demotion is manual and on-brand, not silent decay (V1).

### 2. Public spectacle for official changes

Spec: throttled guild-chat line on promote/demote from approving officer. Norms:

- Prefer announce **on** for demotes that matter socially.  
- Correction announces when undoing a mistaken public promote.  
- Avoid spam: one line, not a sermon (tone track can refine copy).

### 3. Explain harsh calls

Reject / demote / wipe: short reason visible to officers always; to the target when feasible (My Standing or whisper). “On-brand comedy reject” is fine if the target can tell it was intentional.

### 4. Shared officer memory

If only the online officer saw a `SUGGESTION` (§16.5), transparency among officers fails first. Norm: prefer queue sync or “officer of the night posts pending in Discord” until sync exists.

### 5. Consistent administration > clever exceptions

Changing threshold politics mid-season without announcement recreates loot-system mid-tier rebuild drama. Tune after a playtest night; announce Lent resets if added later.

### 6. Audit is for trust, not surveillance theater

[Flagsmith](https://www.flagsmith.com/blog/what-is-the-four-eyes-principle): logs unused except at audit time are wasted. Norm: officers glance Recent Actions after raid night; GM checks after any drama.

## Transparency ladder (what members can expect)

| Layer | Content | Channel |
|-------|---------|---------|
| L0 | Rank titles on ladder | `/beef` Ladder |
| L1 | Own standing + events | My Standing |
| L2 | Official change actor/time | Tooltip / “Last recognized by X” |
| L3 | Guild-chat spectacle | Guild chat |
| L4 | Rubric & FAQ | Discord / footer help |
| L5 | Full audit export | Officers only (later) |

V1 should clear **L0–L3** without heroics. L5 is RCL-export energy — defer.

---

## Anti-norms (avoid)

- Secret officer-only ladder while members see stale titles.  
- Approve with announce, demote without audit.  
- “Trust us” with empty reject reasons during a favoritism argument.  
- Turning every reject into public dunk content (stream comedy ≠ bullying).

---

## Insight

Transparency for Beef is **who decided + what rule applied + public recognition**, not open voting on every Cooked Beef. Match loot-council hygiene, keep church spectacle.
