|\n\n\u2192 Lua functions\n\nReturns a timestamp for the specified time or the current [Unix time](https://en.wikipedia.org/wiki/Unix_time \"wikipedia:Unix time\") .\n\n```\ntimestamp = time([dateTable])\n```\n\n    dateTable\n    table ? \\- Table specifying a date/time to return the timestamp of; if omitted, a timestamp for the current time (per the local clock) will be returned. This table must have fields `year` , `month` , and `day` , and may have fields `hour` , `min` , `sec` , and `isdst` . For a description of these fields, see the [Lua reference manual](http://www.lua.org/manual/5.1/manual.html.date) .\n\n    timestamp\n    number \\- Time in seconds since the [epoch](https://en.wikipedia.org/wiki/Epoch_\\(computing\\) \"wikipedia:Epoch (computing)\") . If applicable, the time for `dateTable` .\n\n* This function is Lua's standard [os.time](http://www.lua.org/manual/5.1/manual.html.time) (), shifted into the global namespace.\n* If not given any arguments, `time()` will return a value based on the local clock, so it is not synchronized among clients. Consider using GetServerTime () instead if you would rather have a value based on the server clock, which IS synchronized among clients.\n\nPrints the current Unix time from the local machine's clock.\n\n```\n/ dump time () -- 1118722038\n```\n\nPrints the Unix timestamp for a specific date.\n\n```\nlocal dateTbl = { \n\t year = 2004 , \n\t month = 11 , \n\t day = 23 , \n } \n\n print ( time ( dateTbl )) -- 1101207600\n```\n\nWhen in a EU time zone CEST (UTC+2) and playing on Moon Guard US, CDT (UTC-5). The examples were taken at the same time. Note that `time()` and `date()` are tied to your system's clock which can be manually changed.\n\n```\n-- unix time\n **time** ()                             -- 1596157547\n GetServerTime ())                   -- 1596157549\n\n-- local time, same as `date(nil, time())`\n date ()                             -- \"Fri Jul 31 03:05:47 2020\"\n\n-- realm time\n GetGameTime ()                          -- 20, 4\n C_DateAndTime.GetCurrentCalendarTime () -- hour:20, minute:4\n C_DateAndTime.GetServerTimeLocal ()     -- 1596139440 unix time offset by the server's time zone (e.g. UTC minus 5
