# White space for Church of Beef

**Product anchor:** Spec §1–4 — social guild / streamer-event institution; rank ladder with hybrid Officer+ approval; not raid optimization or loot fairness.

---

## 1. What the market already saturates

Do **not** compete head-on:

| Saturated job | Why it’s closed |
|---------------|-----------------|
| DKP / EPGP / SK ledgers | [CLM](https://www.curseforge.com/wow/addons/classic-loot-manager) is the living multi-mode default; WebDKP/Monolith/CEPGP are known alternatives ([Guild Order](https://guildorder.com/games/wow/guides/loot-systems-dkp-vs-epgp)) |
| Loot council voting | [RCLootCouncil Classic](https://www.curseforge.com/wow/addons/rclootcouncil-classic) is the universal ML voting UI |
| SoftRes / GDKP / TMB | [softres.it](https://softres.it/) + [Gargul](https://www.curseforge.com/wow/addons/gargul) (track 13) |
| Discord ↔ calendar RSVP ops | [Guilds of WoW](https://guildsofwow.com/) |
| Roster alts/bans/history | [Guild Roster Manager](http://guildrostermanager.com/) |
| RP character directories | TRP3 / MRP (track 13) |
| Combat prestige | Raider.IO / Warcraft Logs |

Any CurseForge blurb that frames Beef as “loot points,” “attendance for raids,” or “RP profile” will mis-sort installs into the wrong stack.

---

## 2. The open wedge

**Theatrical guild standing with Officer+ ritual, fed by co-play / ceremony / challenge — not by boss loot.**

Almost every mature “points” product ties score to *raid resource distribution*. Beef ties standing to *belonging spectacle*:

| Dimension | Typical loot/ops tool | Church of Beef white space |
|-----------|----------------------|----------------------------|
| Currency meaning | EP/GP, DKP, gold, SoftRes priority | Standing toward *titles* (Fresh Beef → Prophet) |
| Authority | ML / council / note editors | WoW Officer+ approve suggestions |
| Primary scene | Boss loot window | Guild chat announce + ladder UI + stream |
| Brand | Neutral admin utility | Absurd religious-sports institution |
| External deps | Often web sync (WebDKP, GoW, softres) | Fully in-game V1 |
| Fun layer | Optional announce strings | Core product (ceremony, Gora, excommunication) |
| Scarcity at top | Decay / GP / wishlist | Council seats + unique Prophet (spec §4.1) |

That combination is **not** owned by CLM, RCLC, GoW, GRM, or TRP3.

---

## 3. Adjacent gaps (secondary white space)

Useful later; do not expand V1 into these unless intentional:

1. **Branded shoutout packs** — Guild Achieve Congratulator proves demand for funny guild-chat bots, but no one ships a full *vernacular* tied to a ladder. Deferred ceremonial dashboard (spec §3.2) can own this.
2. **Devotion streaks as public lore** — Attendance exists inside WebDKP/GoW as ops KPI; nobody markets it as cult devotion with titles. Keep thin in V1 (ceremony mark), expand as lore later.
3. **Streamer-first guild moments** — Platforms optimize officer spreadsheets; few optimize *capture-readable* social beats (see track 17). Beef’s guild-chat promotion line is the cheapest wedge.
4. **Cross-guild rivalry theater** — Cross Guild Chat / recruitment sites don’t run intramural sports shows. Beef Gora is thin in V1; deep match packaging is deferred — still uncontested.

---

## 4. Positioning statements (use / avoid)

### Prefer

- “Guild rank ladder and ceremonies for a streamer-led community.”
- “Officer-approved titles from playing together — not from loot.”
- “Works fully in-game; no website required.”
- “Sits beside GRM / CLM / TRP3 — does not replace them.”

### Avoid

- “DKP / EPGP / loot council alternative”
- “Raid attendance tracker”
- “RP profile addon”
- “Guild management suite” (that’s GoW/GRM)

---

## 5. Coexistence map (install reality)

A progressive Anniversary guild might run:

| Tool | Job |
|------|-----|
| DBM / WA / Details | Combat (Beef must not touch) |
| CLM or RCLC or Gargul | Loot |
| GRM | Roster ops |
| GoW Discord bot | Sign-ups |
| TRP3 (optional) | RP sheets |
| **Church of Beef** | **Institutional standing + spectacle** |

White space holds only if Beef stays in the last row.

---

## 6. Risks that close the white space

| Risk | How it closes the gap |
|------|------------------------|
| Scoring that looks like DKP (boss kill auto-award, item GP) | Players treat Beef as broken CLM |
| Building Discord/web sync in V1 | Competes with GoW before ladder is loved |
| Title UI that looks like TRP3 profiles | RP users expect MSP; loot users ignore |
| Officer queue that clones RCLC voting | Expectation of multi-voter loot drama |
| Expanding into SoftRes/GDKP | Gargul already owns ML spectacle |

Spec V1 scope already avoids these — keep listing copy and feature creep aligned.

---

## 7. One-line market thesis

> The Classic guild-tool market is rich in **loot fairness**, **roster ops**, and **character RP identity**, and poor in **branded, officer-gated, stream-facing social ladders**. Church of Beef should own that empty cell and refuse every adjacent job that already has a category king.
