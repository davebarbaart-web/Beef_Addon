CEPGP Standings Tracker is a plug in for the addon CEPGP. It tracks all changes to peoples EP and GP standings and displays them in a date ordered window accessible by right clicking a name in the guild view within the CEPGP addon. The tracking is not retroactive, but will pick up changes since you last logged in to the game so you do not need to be online for the plugin to keep up to date.

NOTE: Compatible with CEPGP version 1.12.18 or higher.
